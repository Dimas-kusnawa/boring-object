A program that writes one review of the most boring object to `/output/entry.txt` (85 characters, inside the 1–200 character gate): "One star. It has stirred ten thousand cups of tea and never once tasted a single one." A teaspoon that has spent its whole life stirring tea it never gets to taste — the dullness itself is the joke, the detail belongs to the spoon alone, and the last words sharpen it.

## Run it

```sh
python3 main.py
```
